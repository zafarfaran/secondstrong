# 0002 SwiftPM modules and XcodeGen

Status: accepted (agent's call, open to change), 2026-10-20

## Context

The app needs a structure where layer rules are enforced, files stay small, and
agents can change the build without editing a binary-ish `.pbxproj`.

## Decision

- Code lives in SwiftPM modules (SSCore, SSDesign, one per feature). Module
  dependencies enforce layering at compile time.
- The thin app target is generated by XcodeGen from `project.yml`. The
  `.xcodeproj` is gitignored.
- Swift 6 language mode and iOS 17 minimum.

## Consequences

Contributors need `xcodegen` (`brew install xcodegen`). Package tests run on the
macOS host with `swift test`. Moving the minimum iOS version means editing both
`Package.swift` and `project.yml`.
