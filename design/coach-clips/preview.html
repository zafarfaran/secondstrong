Bramble, rendered.

Nine states rendered with HyperFrames as transparent video, the way the app will play them. Press an app event and Bramble finishes the current move, comes back to neutral, and moves into the new state without a jump.

  1. Each clip has three parts: in (neutral to the state), a seamless loop, and out (back to neutral).
  2. An event waits for the loop to finish, plays the out, then the next state's in. Every clip starts and ends on the same neutral frame, so the hand-over is invisible.
  3. Back to Today returns Bramble to idle.

All nine clips

Each whole file looping: in, loop, out. Switch the background to see they're truly transparent.

Files

Masters are ProRes 4444 with alpha (400 × 400, 30fps). The preview uses VP9 WebM with alpha, 170–310 KB per state. On the Mac, one script makes HEVC with alpha for iOS, which is smaller again.

Animation

Anticipation before moves, squash and stretch on the hop, ears that lag and flop, brows that act, eyes that change inside a blink, and a shadow that shrinks in the air.

Checked

Every loop's first and last frames match, and every clip starts and ends on the same neutral frame, measured pixel by pixel.
