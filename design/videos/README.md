# Animation recordings

MP4 recordings of the prototypes, for reference when building the animations in Rive and SwiftUI.

| Video | Length | What it shows |
|---|---|---|
| `cold-start.mp4` | 12s | Icon tap, launch screen, the dot drawing the wire, birds on a wire, Today |
| `intro-birds-on-wire-returning.mp4` | 9s | The chosen intro when someone returns: their coach comes forward |
| `intro-birds-on-wire-first-open.mp4` | 8s | The chosen intro on a first open: the cast greets, onboarding begins |
| `peek-loader.mp4` | 8s | The chosen between-screen loader |
| `onboarding-one-line.mp4` | 35s | The chosen onboarding, played through with real taps |
| `coach-mascot-states.mp4` | 25s | All seven coaches through all nine states |
| `intro-all-five.mp4` | 9s | The five intros compared |
| `between-screens.mp4` | 9s | Coach wipe, peek loader and card to session |
| `loading-moments.mp4` | 9s | The six loading moments |

`node design/videos/record.mjs [name ...]` re-records them from the prototypes (needs Chrome and ffmpeg).
