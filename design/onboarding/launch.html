Second Strong · iOS launch screen

The first half second.

iOS shows the launch screen the instant the icon is tapped, before the app has loaded. It has to be still, and it should look like the app's first frame so the hand-off is invisible. Each option below is the still screen; press play to see how the app picks up from it.

How it's built

  • A UILaunchScreen entry in Info.plist: background colour LaunchBackground and one centred image LaunchMark, both with light and dark variants in the asset catalogue.
  • The ruled lines are part of the image, so the paper texture is there from the very first frame.
  • No text that needs translating, and nothing that changes per member.

Colours

  • Light: page #FBF8F4, ink #3B322C, pen #A85A3C.
  • Dark: page #211B17, ink #F1E9DF, pen #E39874.
  • The first app frame uses exactly the same positions, so nothing jumps when it takes over.

Recommendation

Option 1. It is the calmest, it is literally the first frame of the cold-launch animation, and the stroke under the wordmark is the same pen that runs through onboarding. Option 3 is the warmest if you want the coaches to greet people before anything else.
